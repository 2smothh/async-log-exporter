# Async Log Exporter 🚀

`async-log-exporter` is a high-performance, asynchronous log parsing and exporting engine designed for microservice architectures and high-throughput Python applications.

## Key Features
- **Non-blocking async I/O:** Built with `asyncio` for scalable ingestion without blocking execution threads.
- **Multi-format Support:** Seamlessly export system logs to JSON and CSV formats.
- **Log Level Filtering:** In-memory filtering capabilities for streamlined error debugging.
- **Zero External Dependencies:** Built entirely with standard library Python modules.
